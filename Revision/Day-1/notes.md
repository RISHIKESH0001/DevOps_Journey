# What is DevOps ?

imagine a company like Amazon

A developer writes a shopping website.

After writing the code, what happens?

1. The code is tested.
2. The code is packaged.
3. It is deployed to servers.
4. Servers are monitored.
5. Bugs are fixed.
6. Updates are released.

Years ago, these steps were done by different teams and often took weeks.

DevOps is a culture and set of practices that automate and streamline this process so software can be released quickly and reliably.

A DevOps Engineer typically:

1. Creates servers.
2. Configures Linux.
3. Deploys applications.
4. Sets up CI/CD pipelines.
5. Manages cloud infrastructure.
6. Monitors systems.
7. Automates repititive tasks.
8. Troubleshoots production issues.

You're not writing large applications -- you are making sure they run smoothly.

# Why Linux ?

More than 90% of cloud servers run Linux.

You'll see Linux in:

1. AWS EC2
2. Azure Virtual Machines
3. Google Cloud
4. Docker containers
5. Kubernetes nodes
6. Web servers

Why companies choose Linux

1. Stable
2. Secure
3. Free
4. Fast
5. Excellent for automation
6. Easy to manage remotely

Learning Linux is the foundation of DevOps.
