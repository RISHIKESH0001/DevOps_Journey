# Day 11 Revision Notes

## Important Git Commands 

	Command			Purpose

	git status		Show repository state

	git add			Save changes

	git commit		Create a commit

	git log			View commit history

	git diff		View unstaged changes

	git diff --cached	View staged changes
	
	git branch		List branches

	git branch name		Create branch

	git switch name		Switch branch

	git merge name		Merge branch

	git branch -d name 	Delete branch

	git push 		Send commits to GitHub

	git pull		Get remote changes



## Interview Questions :

1. What is Git?

-> A distributed version-control system used to track changes in code and collaborate.

2. What is GitHub?

-> A remote platform for hosting Git repositories and collaborating on them.

3. Git vs GitHub?

-> Git is the version-control system; GitHub is a platform that hosts Git repositories.

4. What is branch?

-> An independent line of development used to make changes without directly affecting another branch.

5. What is staging?

-> Selecting changes that will be included in the next commit.

6. What is a commit?

-> A snapshot of staged changes stored in the local Git repository.

7. What is a merge conflict?

-> When Git cannot automatically reconcile changes made to the same part of files in different branches.

8. What is a merge pull?

-> It fetches changes from the remote repository and integrates them into your current branch.

9. What is git push?

-> It uploads your local commits to the remote repository.

10. What is git diff?

->It shows differences between versions of your files.
