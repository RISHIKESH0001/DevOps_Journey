# Day 16 Revision notes

## Interview Questions :

1. What is IAM ?

-> IAM is AWS's service for managing identities and permissions.

2. What is an IAM policy ?

-> A policy is a document that defines what actions are allowed or denied on AWS resources.

3. What is least privilege ?

-> Granting only the minimum permissions required to perform a task.

4. What is EC2 ?

-> EC2 is AWS's service for providing resizable virtual compute servers.

5. What is a Security Group ?

-> A virtual firewall that controls network traffic to and from an EC2 instance.

6. What port is normally used for SSH?

-> 22

7. Why do we use a .pem file ?

-> It contains the private key used to authenticate to an EC2 instance through SSH.

8. Why do we use chmod 400 on the key ?

-> To restrict the private key so that only its owner can read it.

9. Difference between stopping and terminating EC2 ?

-> Stop shut downs the instance while retaining it; terminate permanently deletes the instance.

10. What is the AWS equivalent of a cloud virtual machine ?

-> EC2 instance.
