# Day 16 of learning DevOps

1. IAM (Identity and Access Management) controls who can access AWS resources and what they can do.
          
	Components			Purpose

	User				Individual identity

	Group				Collection of users

	Role				Identity assumed by AWS services/users

	Policy				Permissions

	MFA				Additional security

2. MFA (Multi Factor Authentication) adds an additional authentication factor, making account compromise harder even if the password is stolen.

3. EC2 (Elastic Compute Cloud) provides virtual servers in AWS.
