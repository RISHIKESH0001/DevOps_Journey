# Day 14 Revision Notes

## Interview Questions :

1. What does chmod +x do?

-> Adds execute permission to a file.

2. What does > do?

-> Redirects output to a file, overwriting it.

3. What does >> do?

-> Appends output to a file.

4. What does tail -f do?

-> Continuously displays new lines appended to a file.

5. What does git add do?

-> Moves selected changes into the staging area.

6. What does git commit do?

-> Creates a snapshot of staged changes in the local repository.

7. Why use a feature branch?

-> To isolate development from the stable main branch.

8. Why shouldn't logs normally be committed?

-> Logs are generated runtime data and can grow large or contain environment-specific/sensitive information.

9. Why use .gitignore?

-> To prevent specified untracked files from being added to Git.

10. What does git push -u origin branch-name do?

-> Pushes the branch to the remote and establishes its upstream tracking branch.
