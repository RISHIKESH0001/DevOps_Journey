# Day 9 Revision Notes

	Variable		Meaning

	  $0	                Script name

	  $1			First argument

	  $2			Second argument

	  $#			Number of arguments

	  $@			All arguments

	  $?			Previous command's exit status

	These are very important bash concepts.


## Interview Questions :

1. What is loop?

-> A mechanism for repeatedly executing commands.

2. for vs while?

-> for is commonly used when iterating through a known list; while runs while a condition is true.

3. What is $1?

-> The first argument passed to a script or function.

4. What is $#?

-> Number of arguments passed to the script.

5. What is $@?

-> All arguments passed to the script.

6. What is a function?

-> A reusable block of commands.

7. What does && mean?

-> Execute the next command if the previous command succeeds.

8. What does || mean?

-> Execute the next command if the previous command fails.

9. Why are Bash scripts useful in DevOps?

-> They automate repititve server administration, deployments, health checks, backups, log processing, and other operational tasks.
