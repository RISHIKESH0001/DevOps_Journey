# Day 15 - AWS Fundamentals

## Cloud Computing

Cloud computing provides computing resources on demand.

## AWS 

AWS = Amazon Web Services

## Region

A geographical AWS location containing AWS infrastructure.

## Availability Zone

An isolated infrastructure location within an AWS Region.

## IAM 

Identity and Access Management

Controls who can access resources and what actions they can perform.

## IAM User

An identity used to interact with AWS.

## IAM Group

A collection of users that can share permissions.

## IAM Role

An identity that can be assumed by usersor AWS services.

## IAM Policy

Defines permissions.

## EC2

Elastic Compute Cloud.
Provides virtual servers. 

## AMI

Amazon Machine Image.
A template used to launch EC2 instances.

## Security Group

Acts as a virtual firewall for AWS resources such as EC2.

## Important Ports 

22 = SSH

80 = HTTP

443 = HTTPS

## Important Security Rules

- Protect AWS credentials. 
- Never commit private keys to Git.
- Use IAM instead of root for daily work.
- Enable MFA.
- Avoid unnecessary open ports.
- Check billing before creating resources.
