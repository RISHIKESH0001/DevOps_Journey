# Day 13 Revision Notes

## Interview Questions :

1. What is origin?

-> The conventional name for a remote repository.

2. What is origin/main?

-> A remote-tracking reference representing the state of the remote main branch known to your local Git repository.

3. What does git fetch do?

-> Downloads remote updates without integrating them into your current branch.

4. What does git branch -r show?

-> Remote-tracking branches.

5. What is a Pull Request?

-> A request to review and merge changes from one branch into another.

6. Why use feature branches?

-> To isolate work and protect the stable main branch.

7. What is upstream?

-> Usually the remote pointing to the original repository when working from a fork.

8. Why protect main?

-> To prevent unreviewed or broken changes from being directly merged into the stable branch.

9. What is a Git tag?

-> A named reference to a specific point in Git history, often used for releases.

10. What is semantic versioning?

-> A versioning scheme commonly represented as MAJOR.MINOR.PATCH .
